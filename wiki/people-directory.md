# People Directory operations

People Systems · 2026-09-09

People Directory serves committed employee and leave snapshots. It is read-only and is not the system where leave approvals happen. The snapshot date is part of the leave response.

The service starts with a Java 21 JDK and the standard library. Do not provision a payroll database for the local demonstration. Customer-account linking is an explicit lookup for selected employee records; an absent link is normal.

Names and work emails may resemble Accounts data because an employee can also be a customer. People identifiers remain emp- identifiers, and customer identifiers remain cus- identifiers. Directory troubleshooting should preserve that distinction.
