# Engineering image collection

These PNGs were retained from architecture reviews and team workshops between January and September 2026. Dates and labels are part of each image. Some drawings describe a release, others a target state or a process discussion.

Read arrows, legends, boundaries, and annotations together. A drawn connection can be useful evidence without proving an executable call path. Compare diagrams with source, deployment configuration, meeting records, and release history when answering engineering questions. The images are distributed as raster files for multimodal investigation.
